# AquaLink Markdown GitHub Pages Portfolio

A Markdown/Jekyll portfolio for the CPUT Project Presentation 3 Portfolio of Evidence assessment.

## Publish to GitHub Pages

1. Create a **public** GitHub repository, e.g. `AquaLink-Portfolio` (do not upload secrets).
2. Upload all files **from inside this folder** to the repository root, including `_config.yml`, `index.md`, and the `evidence` folder.
3. In the repository select **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main**, folder **/(root)**, and **Save**.
6. Wait for deployment, then open `https://YOUR-USERNAME.github.io/AquaLink-Portfolio/`.
7. Verify every page and evidence link before submitting the **GitHub Pages URL** on Blackboard.

## Important

- Complete every `[ADD ...]` and `[WRITE ...]` placeholder with authentic evidence and your own reflection.
- The provided logbook is evidence; it does not replace the team charter, Trello cards, or personal reflections.
- If your repository name differs, GitHub Pages will use that repository name in the URL.
- Do **not** add `.nojekyll` because Jekyll is used to convert Markdown to HTML.
- Update project facts if your current implementation differs from the dated logbook.
